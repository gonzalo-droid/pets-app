# Código heredado sin publicar

`lost/` es el módulo de mascotas perdidas del proyecto anterior. Está fuera del
alcance actual de HUELLAS, así que sus páginas se sacaron de `src/app` (no
generan rutas). Para reactivarlo, mover la carpeta de vuelta a
`src/app/(public)/lost` y revisar sus datos y permisos.
